## What?

In true community spirit and as a statement against elitist gatekeeping, this project serves as an invitation to hacker culture by blasting people with hacker culture where they least expect it.

Join us. Dig into the jokes and discover new worlds. 🌍

Or don't. No one is forcing you to walk through this unkept gate. You're just choosing not.<br/>
No loitering tho.


## How?

It has a server and a client mode.<br/>
In server mode (default), you can just call any number with a SIP client and get the experience. Locally and offline.

In client mode, it can accept calls routed in from the real world.

Go ask an LLM how to set this up.<br/>
